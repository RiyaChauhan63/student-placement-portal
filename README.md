# CampusHire - Student Placement Portal

A student placement portal built with HTML, CSS and JavaScript (no frameworks).

## Features
- Company cards and table (company, role, package, eligibility, deadline)
- JavaScript filters: search, CGPA, branch, minimum package, sorting
- Student application form with field-by-field validation and eligibility check
- Submission confirmation pop-up with application ID
- My Applications status panel (saved with localStorage)
- FAQ accordion (additional interactive section)
- Responsive layout with mobile menu

## Run
Open `index.html` in any browser. No installation needed.

## Files
- `index.html` structure
- `style.css` design and responsive layout
- `script.js` all functionality
